# 7×7 隐藏形状游戏：最优点击策略

## 1. 问题

- 7×7 = 49 个格子。
- 5 个形状，各 1 个，**固定朝向**（不可旋转 / 翻转），只能平移，互不重叠：
  - 横条 2 格 `H2`：`(0,0)(0,1)`
  - 竖条 2 格 `V2`：`(0,0)(1,0)`
  - L 形 3 格 `L3`：`(0,0)(0,1)(1,0)`（朝向左上角的那种，缺右下）
  - 正方形 4 格 `SQ4`：`(0,0)(0,1)(1,0)(1,1)`
  - 鹿形 5 格 `DEER5`：`(0,0)(0,1)(1,0)(1,1)(1,2)`
- 共占 16 格。
- 点击一个格子，**只揭示这一格**是否被某形状覆盖（命中/空格）。
- 必须把所有 16 个被覆盖的格子都点一遍。
- 目标：让**总点击次数**最小。因为 16 个命中格必须点，所以
  **总点击 = 16 + 空格点击数**。
  于是问题等价于：**在贝叶斯推断下，最小化期望的“空点”次数。**

布局先验假设：所有合法布局等概率（即每个形状在所有可行位置里均匀放置后，只保留互不重叠的组合）。合法布局总数：**11,018,662**。

## 2. 这本质上是什么问题

这是一个**部分可观测马尔可夫决策过程（POMDP）**，也可以看成带**非对称代价的最优决策树**：
- 状态 = “与已有观测一致的布局集合”；
- 每次点击是一个“是/否”测试；
- “是（命中）”的代价为 0（因为这一格本来就必须点），“否（空格）”的代价为 1；
- 当所有格子的状态都被确定（即真实布局的 16 格全部已知）时结束。

一般的最优决策树问题是 NP 难的，且这个实例有上千万个可能布局，因此**不存在一个简单的、可闭式推导的“万能公式”**。但可以：

1. 用精确贝叶斯推断把状态压缩成“可能布局的集合”；
2. 用一个几乎最优的规则在线计算下一步。

## 3. 结论：推荐的策略

> **每一步，把所有与你已看到的格子的状态不矛盾的布局列出来；在还没点过的格子里，点“当前最可能被覆盖”的那一格（覆盖它的布局比例最大）。如果某格在全部剩余布局里都被覆盖（100%），直接点它——必中且免费。**

这就是一个清晰、可程序化的规则（“最大后验占用率贪心”）。它不需要你手工枚举，程序会替你维护“与观测一致的布局集合”。

### 为什么这个贪心规则几乎是“最优”的

- 对**只剩两种可能布局**的情况，可以严格证明它最优：此时唯一有信息量的点击是两者不同的格子；点它时“浪费”的概率恰好是少数派布局的后验概率，选后验占用率最高（即少数派概率最低）的格子即可，点完就确定了。
- 把先验缩小成随机小样本后，可以用精确 expectimax 算出**真正的最优策略**并与贪心对比（`exact_vs_greedy.py`）：

  | 可能布局数 S | 贪心空点 | 精确最优空点 | 相对差 |
  |---|---|---|---|
  | 7 | 1.000 | 0.988 | 1.20% |
  | 9 | 1.148 | 1.130 | 1.64% |
  | 11 | 1.242 | 1.227 | 1.23% |
  | 12 | 1.299 | 1.285 | 1.08% |
  | 13 | 1.353 | 1.340 | 0.96% |

  绝对差距只有约 0.01–0.02 次空点，说明贪心已经非常接近最优。
- 用一步前瞻（先试某格，再用贪心收尾）评估开局的 49 个候选，最优开局与贪心开局几乎并列（差 < 0.1%），说明开局不敏感。
- 用纯信息增益（不考虑命中免费这一点）反而更差：平均空点 13.81，而代价感知的贪心是 12.58。这验证了“最大化后验占用率”比“最大化信息量”更合适。

## 6. 性能（蒙特卡洛模拟）

| 策略 | 平均空格数 | 平均总点击（16+空格） |
|---|---|---|
| 随机顺序固定点 | 约 31.1 | 约 47.1 |
| 按先验概率从高到低固定顺序 | 约 28.8 | 约 44.8 |
| **贝叶斯贪心（本策略）** | **约 12.6** | **约 28.6** |

（对 100–200 局、从全部 11,018,662 个合法布局中均匀抽真值做蒙特卡洛；用 `solver.py` 实际逐局跑 40 局得到平均空格 12.0、平均总点击 28.0，与模拟一致。单局空格的波动范围约 6–19，即总点击约 22–35。）

可以看到，自适应地利用“形状 + 观测”信息，把期望总点击从 ~45 降到 ~29，接近理论下界 16。

## 7. 怎么用程序

见同目录：

- `enumerate_configs`（`enumerate.py` / `solver.py` 内置）：枚举全部合法布局，存成 `configs.npy`；
- `solver.py`：贝叶斯求解器，输入你已看到的格子，输出下一步。

运行：

```
python solver.py
```

然后输入观测，例如：

```
next                 # 让程序给出下一步
(5,1)=1              # 记录第 5 行第 1 列“命中”
(5,2)=0              # 记录 (5,2) 是空格
show                 # 打印当前后验覆盖概率图
quit
```

程序内部每一步都会：
1. 用位集合对 11,018,662 个布局做条件筛选；
2. 统计每个未点格子的后验覆盖概率；
3. 返回概率最大的格子（若存在 100% 必中的格子，先点它）。

## 8. 注意事项 / 可扩展

- **L 形的朝向**：本报告取 `(0,0)(0,1)(1,0)`。若游戏里的 L 是字母 L 形 `(0,0)(1,0)(1,1)`，合法布局数变成 10,990,878，先验图和第一步会变（第一步变成 `(1,4)`），但**期望性能几乎不变**（平均空格 12.56，对比 12.58）。改 `SHAPES["L3"]` 即可，方法完全一样。
- **如果点击还揭示“这是哪个形状”**：那信息更多，期望空格会更少。本程序默认“只揭示命中/空格”这一较难、较保险的情形；若需要，可扩展为按形状标签分区。
- 精确的全局最优决策树代价极高，这里给出的是有强证据支持的近最优策略；若你想，我可以继续做更深的期望前瞻 / 策略迭代来进一步逼近最优。
