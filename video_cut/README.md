# 视频剪辑器（带 GUI，多画面合成）

在应用内：扫描视频/图片素材 → 拖入时间轴 → 多轨拼接、PiP 画中画摆放、
变速、调音量、裁剪 → 一键导出合成视频。**免安装绿色版**，ffmpeg 已内置。

## 快速开始

> ⚡ **快速成片**：工具栏点「⚡快速成片」→ 多选素材 → 选转场/分辨率 → 导出，三步出片。

## 快速开始

```
dist\video_cut_app\        ← 整个文件夹拷走即用
  └─ video_cut_app.exe     ← 双击运行（无需装 Python / ffmpeg）
```

## 使用步骤

1. 启动后左侧选**素材文件夹**，文件列表自动出现（🎞 视频 / 🖼 图片）。
2. 双击素材 **加到主轨**（满屏，依次拼接）；点"→ 画中画轨"加到叠加层。
3. 在时间轴上：
   - **单击**选中 → 右侧**属性侧栏**立即显示该片段参数
   - **双击** → 预览播放
   - **拖动** → 移动片段时间位置；**拖边缘** → 裁剪源区间
4. 右侧侧栏可改：源起点/终点、时长、速度、音量、淡入淡出、不透明度；
   **画中画**区填 X/Y/宽/高，或用"位置预设/大小预设"一键摆好；改完点"✔ 应用修改"。
5. 点工具栏或侧栏顶部 **🎬 导出视频** → 选格式/画质/输出路径 → 开始渲染；
   完成后弹窗显示成品**完整路径**，可"打开所在文件夹"直达。
6. 渲染结果自动在预览区播放，可检查效果。

## 常见场景（你提的需求 → 怎么做）

- "视频1 在左上、视频2 在右上、视频3 前 10 分钟在右下、右下常驻一张图片"
  1. 三个视频都点"→ 画中画轨"（各占一层，互不影响）；
  2. 分别选中，在右侧侧栏的"画中画"区用位置预设摆到 左上/右上/右下，
     大小可填宽高或点"1/4、1/2"等比例按钮；
  3. 视频3 裁剪：把侧栏"源终点"设为 10 分钟（600 秒）
     或拖它的右边缘到 10 分钟处；
  4. 图片点"→ 画中画轨"得到默认右下角常驻，改时长覆盖整个项目时长；
  5. 导出。
- 三视频拼接成一个：全部加到**主轨**（依次自动接续）。

```
├── editor/

│   ├── theme.py            # 深色主题
│   ├── engine.py           # 合成引擎（分轨中间文件两段式渲染）
│   ├── preview.py          # 应用内播放器
│   ├── timeline_widget.py  # 时间轴控件
│   ├── project_store.py    # 项目存取 + 自动保存
│   └── editor_app.py       # 主界面
├── test_engine.py          # 引擎回归测试
├── test_ui_smoke.py        # UI 冒烟测试
└── PROGRESS.md             # 开发进度笔记（改代码前必读）
```

- 运行源码版：`python video_cut_app.py`
- 重新打包：`build_exe.bat`（产物在 `dist\video_cut_app\`）
- 回归测试：`python test_engine.py` 和 `python test_ui_smoke.py`

## 说明与限制

- 预览画面与声音按"墙钟"对齐（±100ms 级），正式成片以渲染输出为准
- 输出为 MP4(H.264+AAC)；更多格式/码率预设、转场、滤镜、字幕等
  见 `docs\GAP_ANALYSIS.md`（vs 剪映的差距分析和升级路线）
- 崩溃/报错都记录在 `logs\app.log`，遇到问题先看它
