# 差距分析：本剪辑器 vs 剪映（CapCut）

> 目的：搞清楚"除了复杂功能，还差哪些东西"，据此排优先级一步步完善。
> 状态图例：✅ 已有 | 🟡 部分/简版 | ❌ 没有（待规划）

## 一、素材与预览

| 能力 | 剪映 | 本工具 | 备注 |
|------|------|--------|------|
| 视频/图片/音频导入 | ✅ | ✅ | 🎞🖼🎵 三类 |
| 应用内播放（画面+声音） | ✅ | ✅ | 声音：sounddevice 流式；画面帧流 |
| 拖动进度条/帧级定位 | ✅ | 🟡 | 预览 seek 到秒级；帧级需 snap 关键帧 |
| 播放速度 0.5x/2x 预览 | ✅ | 🟡 | 跟随片段 speed；无独立播放倍率 |
| 素材缩略图 | ✅ | ❌ | 可加（Pillow 生成） |
| 字幕文件（srt）导入 | ✅ | ❌ | 接口已留（effects/轨型） |

## 二、时间轴与剪辑

| 能力 | 剪映 | 本工具 | 备注 |
|------|------|--------|------|
| 多轨时间轴 | ✅ | ✅ | 主轨 + 多层画中画 + 音频轨 |
| 拖移/裁剪/分割 | ✅ | ✅ | 拖边缘裁剪源，播放头分割 |
| 撤销/重做 | ✅ | ✅ | Ctrl+Z/Y，50 步快照 |
| 复制/粘贴片段 | ✅ | ✅ | Ctrl+C/V，粘贴到播放头自动找空位 |
| 吸附（磁吸到片段边缘/播放头） | ✅ | ✅ | 拖移/裁剪双向磁吸，可开关 |
| 关键帧动画（位置/缩放随时间变化） | ✅ | ❌ | 引擎可支持（t= 表达式） |
| 波纹删除/自动接缝 | ✅ | ✅ | 波纹删除 + 闭合空隙（全轨/本轨） |
| 快速/慢速曲线变速 | ✅ | 🟡 | 视频渐变速度（起速→末速线性）；音频按平均速度 |
| 多选片段/批量编辑 | ✅ | ❌ | 后续 |
