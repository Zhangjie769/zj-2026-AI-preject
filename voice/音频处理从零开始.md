# 第 1 章 声音是什么

> **开场场景**：你在体育馆里远远喊朋友，他听出是你，还听出你在喊什么。一秒钟之内，你的声带、空气、他的耳朵完成了一次复杂的信息传递。这一章讲清楚这次传递靠的是什么。

## 1.1 声音的产生：振动是唯一来源

**定义**：声音 = **空气压力的振动**沿空间传播形成的波。

**拆开看**：你喊话时声带在振动 → 压缩旁边的空气（变密）→ 密的部分推动下一层空气 → 形成一圈圈"疏—密—疏—密"交替的波 → 传到朋友耳朵里 → 鼓膜跟着振动 → 大脑翻译成"他在喊我吃晚饭"。

**生活例子**：
- 弹吉他：弦在振动，琴箱把振动放大
- 拍手：手掌之间的空气被瞬间压缩，形成一个"啪"的脉冲
- 雷声：闪电把空气急剧加热膨胀，产生巨大振动，这就是"打雷"的声音

**几个有用的数字**（记不住没关系，混个脸熟）：
- 声速 ≈ **343 米/秒**（20°C 空气中）
- 看到闪电后过 3 秒听到雷声 → 雷在约 **1 公里**外（343×3≈1公里）
- 波长 = 声速 ÷ 频率。440Hz 的声音波长 ≈ 343/440 ≈ **0.78 米**

> 📌 **记住**：声音 = 一个随时间起伏变化的物理量。任何声音都对应一条"时间–气压"曲线，这条曲线叫**波形（waveform）**。全书你都在和这条曲线打交道。

## 1.2 描述声音的三个基本量

一条波曲线，只需要三个量就能完全描述。

| 量 | 它管什么 | 单位 | 直观感受 |
|---|---|---|---|
| **频率** | 每秒振动多少次 | 赫兹（Hz） | 音调高低 |
| **振幅** | 振动幅度多大 | （相对值或 dB） | 音量大小 |
| **相位** | 波从哪一点开始起伏 | 弧度/度 | 单个声音时耳朵几乎听不出 |

### 频率（Frequency）——决定音调高低

**定义**：每秒完成多少次完整振动。振动越快，音调越高。

**例子**：
- 男声说话基频大约 **85–180 Hz**，女声大约 **165–255 Hz**，所以女声显得"尖"
- 婴儿哭喊可以到 **500 Hz 以上**，又尖又亮
- 电话按键的"嘟"是 **440 Hz**（美国标准），"嘟——"和"嘀"就是频率不同
- 钢琴最低音 A0 是 27.5 Hz，最高音 C8 是 4186 Hz

**一个超重要的规律**：频率翻倍 = 音调升**一个八度**。440 Hz 是标准音 A4，880 Hz 是高一个八度的 A5，220 Hz 是低一个八度的 A3——三者的关系人耳一听就知道"是同一个音，只是高低不同"。

**人耳范围**：**20 Hz ~ 20,000 Hz**。低于 20Hz 是次声波（大象交流用），高于 20kHz 是超声波（蝙蝠定位用，所以"超声波"这个词你并不陌生）。

> 🎯 **生活例子**：打电话为什么觉得声音"闷"？因为电话只传输 300–3400 Hz。它保留了让你听清说话内容的频段，但丢掉了高频的"光泽感"，所以熟人声音在电话里依然认得出来（音色信息集中在较低频段），但感觉"干瘪"。

### 振幅（Amplitude）——决定音量大小

**定义**：波形偏离平衡位置的最大程度。振幅越大，空气被推得越猛，你听到的越响。

**分贝（dB）**：声音强弱范围太大（最轻到最响相差 1 万亿倍），所以用**对数刻度**——分贝。

**定义式**：`dB = 20 × log₁₀(A₂/A₁)`，其中 A 是振幅。

**几个公式速记**（以后天天用）：
- 振幅 ×2 → **+6 dB**
- 振幅 ×1.41（√2）→ **+3 dB**
- 振幅 ÷2 → **-6 dB**
- 振幅 ×10 → **+20 dB**

**现实中的分贝标尺**（声压级 SPL，0 dB 是人耳能听到的最轻声音）：

| 场景 | 大约分贝 |
|---|---|
| 耳语 | 30 dB |
| 正常交谈 | 60 dB |
| 割草机/嘈杂街道 | 90 dB |
| 摇滚演唱会前排 | 110 dB |
| 疼痛阈值 | 130 dB |

> 🧠 **直觉**：人耳觉得"响了一倍"，大约需要 +10 dB（即能量×10，振幅×3.16）。所以 90dB 的割草机比 60dB 的交谈"响"很多倍——不是 1.5 倍，而是 2^(3×3.16)≈ 大约 8~10 倍的心理响度。分贝是个"吞掉大数字"的压缩尺子。

### 相位（Phase）——叠加时的关键

**定义**：某个时刻波形处于振动周期的哪个位置。比如正弦波从 0 开始爬升（相位 0）还是已经从峰值往下掉（相位 90°）。

**相位单听几乎无感，但叠加时是生死攸关的**——这不是抽象概念，你每天都被它服务着：

> 🎧 **最佳例子：主动降噪耳机**。耳机外置麦克风采集环境噪声（比如飞机引擎声），然后芯片**生成一个相位正好相反（差 180°）的同样的波**，两个波叠加时正好抵消——这就是"反相消噪"。你戴降噪耳机时，耳朵里其实存在两个巨大的声波在互相打架，正好同归于尽，你听到的就是安静。

**如果你一定要感受一次相位**：
```python
import numpy as np, soundfile as sf
sr = 44100
t = np.arange(0, 2, 1/sr)
w = np.sin(2*np.pi*440*t)
sf.write("sine.wav", w, sr)                    # 正常
sf.write("sine_inv.wav", -w, sr)               # 反相：听起来一模一样
sf.write("sum_zero.wav", w + (-w), sr)         # 相加 = 全零 = 静音！
```
前两个文件听起来完全相同，第三个文件是"两个响亮的 440Hz 音互相抵消后的安静"——这就是降噪耳机的魔法。

## 1.3 音色（Timbre）：为什么钢琴和小提琴弹同一个音不一样

**问题**：A4（440 Hz）这个音，钢琴弹出来和小提琴拉出来，音调一样、音量一样，你一耳朵就能分辨谁是谁。凭什么？

**答案**：**音色**。真实乐器的声音不是单一的正弦波，而是：

- **基频**：440Hz，决定音调
- **泛音（谐波）**：880Hz、1320Hz、1760Hz……（基频的整数倍），各自的强弱比例不同

钢琴的 440Hz 音，泛音 A、D（每个音符的泛音分布）分配得"宽厚"；小提琴的泛音则"纤细锐利"。**音色 = 各频率成分的强弱分布 = 频谱的形状**。

**再举一个你天天遇到的例子**：你的熟人给你打电话，为什么听得出来是"他"？因为每个人的声带振动和口腔形状不同 → 泛音分布不同 → 音色指纹不同。**声音的"身份"藏在频谱里**，不是藏在基频里。

> 🔬 **小实验**：以后我们会写代码把一段声音"拆开"看频谱（第 6 章）。现在你可以先在 Audacity 里打开一段钢琴声和一段小提琴声，菜单"分析 → 绘制频谱图"，看看两者的"山峰形状"有多不一样。

## 1.4 本章小结与测验

**本章要点**：
1. 声音 = 空气压力振动，任何声音可画成"时间–气压"波形
2. 频率→音调，振幅→音量，相位→叠加时的关键
3. 人耳 20Hz~20kHz；频率翻倍=升八度；响亮一倍≈+10dB
4. 音色 = 频谱形状；所有"听起来不一样"的秘密都在频谱里

**测验**（答案在附录 D）：
1. 女声 220Hz，男声 110Hz，哪个高？高多少？
2. 振幅乘以 0.5，音量减小多少 dB？
3. 泛音是什么？为什么它决定音色？
4. 主动降噪耳机靠什么物理原理降噪？

# 第 2 章 把声音装进电脑：数字化

> **开场场景**：电影里马车的轮子越转越快，突然开始"倒转"了——明明车轮在向前滚。这不是特效，是采样原理在作怪。这一章讲清楚"把连续的声音变成离散数字"的全部秘密。

## 2.1 为什么必须数字化

**问题**：声音是连续变化的物理量（模拟信号）。但电脑只能存不连续的 0 和 1（数字）。所以中间必须有一道"翻译"工序。

**为什么数字赢麻了**：
- 磁带（模拟）翻录一次，噪声就累积一次，越拷越糊
- 数字文件拷贝一万次，每一份都和原件一字不差（你拷过 mp3 吧，从来没听说"拷糊了"）

**这道翻译工序叫 ADC**（Analog-to-Digital Converter，模拟转数字），录音设备里人人都有。翻译只需回答三个问题：

> **① 每隔多久记一次？→ 采样率**
> **② 每次记多精细？→ 位深**
> **③ 同时记几路？→ 声道**

## 2.2 采样（Sampling）：每隔多久记一次

**定义**：每隔固定时间间隔，把波形当时的数值"截一个快照"记下来。每秒记多少次叫**采样率**，单位 Hz。

**经典比喻：动画帧率**。动画每秒 24 帧，动作流畅；每秒 5 帧，动作一顿一顿。采样率就是声音的"帧率"——每秒 44100 帧（44.1kHz）流畅无比，每秒 8 帧（8kHz 电话）就"卡顿"成闷闷的声音。

**"拍照"与"重建"**：录音 = 拍照（只留一个点），播放 = 把点连成线（重建波形）。点的密度越高，重建越接近原曲线。

**奈奎斯特采样定理**（工程师的命根子）：

> **要无失真地表示一个频率为 f 的信号，采样率必须 ≥ 2f。**

- 44.1kHz 采样率 → 能表示 **22.05kHz** 以下 → 覆盖人耳 20kHz 上限 + 余量 ✔️
- 电话 8kHz 采样率 → 只能表示 4kHz 以下 → 所以电话"闷" ✔️（第 1 章的闷，根源在这里）

**混叠（Aliasing）——采样界的"轮子倒转"**：
为什么电影里车轮会倒转？摄像机的采样率（24 帧/秒）跟不上车轮转动的频率（比如每秒转 20 圈），于是"轮的辐条"每次拍到都在倒退一点点，眼睛（大脑重建）就脑补出"倒转"。

声音里一模一样：如果一个高频声音（比如 15kHz）混进了 8kHz 采样率的录音，它会被"伪造成"一个低频率的怪声——这就是**混叠**。所以：
- 语音通话芯片会先把高于 4kHz 的成分**滤掉**再采样，防混叠
- 好的采样器会在 ADC 前加一个**抗混叠低通滤波器**

> 📝 **例题**：给一个"最高频率 10kHz"的音频做数字化，采样率至少多少？→ **至少 20kHz**（实际工程上会留余量，比如 24kHz 或 44.1kHz）。

## 2.3 量化（Quantization）：每次记多精细

**定义**：每次采样得到的振幅值，要用固定位数的二进制存。位数叫**位深（bit depth）**。

**经典比喻：用"厘米尺"量身高**。
- 身高 172.4cm，用厘米尺只能记"172cm"，差了 0.4——这就是**量化误差**
- 尺子的刻度越细（位深越高），误差越小
- 位深 16 bit = 65536 个刻度；24 bit = 1600 多万个刻度

**量化误差听感**：像一层极微弱的"沙沙"底噪（量化噪声）。录音棚用 24 bit 就是为了让这层噪声远低于人能感知的水平。

**动态范围**：位深决定了能同时表达"多轻"和"多响"。每多 1 bit ≈ 多 **6 dB** 动态范围：

- 16 bit → 20×log₁₀(65536) ≈ **96 dB**（CD 音质，约等于"耳边细语到雷声"的范围）
- 24 bit → **144 dB**（录音棚标准）

**总结一句**：**采样率管"时间上够不够细"，位深管"数值上够不够细"**。

## 2.4 声道（Channels）：同时记几路

- **单声道（Mono）**：一路数字，一个麦克风的感觉
- **立体声（Stereo）**：左右两路，模拟两只耳朵。人的双耳效应能定位声源方向，所以立体声有"空间感"
- **多声道**：5.1、7.1 环绕声（家庭影院），多路数字

**小知识**：单声道文件用耳机听，左右耳内容一样，声像"在正中间"；立体声文件如果左右不同，你能听出"吉他偏左、人声居中、鼓偏右"——这就是立体声的魔力。

## 2.5 数据量：算一笔账（必须会算）

**公式**：每秒数据量（字节）= 采样率 × 位深÷8 × 声道数

**例题 1**：CD 立体声（44.1kHz / 16bit / 2声道）一秒多少字节？
$$44100 × 2 × 2 = 176{,}400 \text{ 字节/秒} ≈ 172 \text{ KB/s}$$

**例题 2**：一分钟呢？→ 176400 × 60 ≈ **10.1 MB**。一首 4 分钟的歌 ≈ 40MB！

**常用配置一览表**：

| 配置 | 每秒数据量 | 1 分钟 |
|---|---|---|
| 8kHz 单声道 16bit（电话） | 16 KB | ~0.9 MB |
| 44.1kHz 单声道 16bit | 88 KB | ~5.1 MB |
| 44.1kHz 立体声 16bit（CD） | 176 KB | ~10.1 MB |
| 48kHz 立体声 24bit（影视） | 288 KB | ~16.9 MB |

> 💡 **重要领悟**：这就是为什么存在 MP3/FLAC——**原始数字太大**。第 3 章的所有"压缩"都是为了对付这张表。

## 2.6 常见采样率与位深速查

| 采样率 | 用在哪儿 |
|---|---|
| 8 kHz | 电话、对讲机 |
| 16 kHz | 语音识别/AI 标配（人声主要能量在 4kHz 以下，够用又省） |
| 44.1 kHz | CD、音乐 |
| 48 kHz | 视频、影视、游戏 |
| 96 kHz | 高保真录音 |

| 位深 | 用在哪儿 |
|---|---|
| 16 bit | 最终成品（CD/分发） |
| 24 bit | 录音/制作过程（留余量） |
| 32 bit float | 代码里的"中间工作格式"（第 4 章细讲） |

## 2.7 本章小结与测验

**要点**：
1. 数字化三问：采样率（多久记一次）、位深（记多细）、声道（记几路）
2. 奈奎斯特：采样率 ≥ 2×最高频率；不满足就混叠（车轮倒转）
3. 位深每 +1bit ≈ +6dB 动态范围
4. 数据量=采样率×位深÷8×声道；这就是压缩存在的理由

**测验**：
1. 20kHz 的声音要无失真数字化，采样率至少多少？
2. 24 bit 比 16 bit 多多少动态范围？
3. 为什么语音 AI 常用 16kHz 而不是 44.1kHz？
4. 电影里车轮倒转的现象叫什么？音频里对应什么危害？

# 第 3 章 音频文件格式：从 WAV 到 MP3

> **开场场景**：你在网易云下载了"320kbps 高品质"的 mp3，手机里还有一段录像（mp4）。两者都是音频载体，但一个只有声音、一个装着声音+画面，文件体积天差地别。这一章把所有"格式"一次讲清。

## 3.1 一个必须分清的核心概念：编码 vs 容器

这是格式迷宫的钥匙，先建好它：

| | 编码（codec） | 容器（container） |
|---|---|---|
| **管什么** | 声音数字**用什么算法压成 0/1** | 各种轨道**怎么打包进一个文件** |
| **类比** | 货物本身（一箱苹果） | 快递纸箱（上面写着装箱单） |
| **例子** | PCM、MP3、AAC、FLAC、Opus | WAV、MP4、MKV、M4A、OGG |
| **一句话** | "听起来怎样" | "文件长什么样" |

**理解这两个词，你就理解了一切**：
- **MP3**：既是一种编码，也直接当文件后缀用（通常没有额外容器，文件=编码数据本身）
- **MP4**：是容器。它可以同时装"视频轨道(H.264/H.265) + 音频轨道(AAC) + 字幕"
- **M4A**：MP4 容器的"只有音频"版本——所以 **"从 mp4 提取音频"最优雅的产物就是 m4a**：同样的容器，只是把视频轨道去掉

> 🎯 **回答一个经典疑问**：为什么要分两种"格式"？因为**同一套压缩算法可以放进不同的箱子**。AAC 编码可以装进 MP4 箱子（.m4a），也可以装进 ADTS 流（.aac）；视频同理。你只要知道 **编码决定音质，容器决定兼容性** 就够了。

## 3.2 WAV：最直白的格式（学习的首选）

**WAV = 容器（RIFF）+ 编码（PCM）**。PCM 就是第 2 章那串原始数字，一个字不改。

**解剖一个 wav 文件**（用十六进制编辑器或 `xxd` 打开，你会看到清晰的结构）：

```
52 49 46 46  xx xx xx xx   "RIFF" + 总长度
57 41 56 45                 "WAVE"
66 6d 74 20  10 00 00 00    "fmt " 块 + 长度16字节
01 00  02 00               audio format=1(PCM), 声道=2
44 ac 00 00               采样率 44100
10 b1 02 00 00 00 00 00   字节率等
64 61 74 61  xx xx xx xx   "data" 块 + 数据长度
[这里开始就是原始 PCM 数字……]
```

文件头部（几十字节）交代"采样率 44100、16bit、立体声"，之后全是实实在在的声音数字。**没有压缩、没有魔法**。

```powershell
# 在命令行看你的第一个 wav 的头部（用 Python 生成一个先）
py -c "import numpy as np,soundfile as sf; sf.write('t.wav', 0.5*np.sin(2*np.pi*440*np.arange(44100)/44100), 44100)"
# 然后可以用 ffprobe 看它：
ffprobe t.wav
```

**所以 WAV 为什么体积大？** 因为它就是"原始数字"本身。但也因此它是**学习的首选**：读进代码里你看到的就是第 2 章那张表格，没有任何障碍。

> ⚠️ **常见误区**：有人说"wav 音质比 mp3 好"。准确说法是 wav(PCM) **信息无损**，mp3 **有损**。但"听感"取决于码率——320kbps 的 mp3 盲听多数人分不出和 wav 的区别。**学习时用 wav（看得见摸得着），发布时用 mp3（体积合理）**。

## 3.3 MP3：它到底"狠心丢掉了什么"

**一句话原理**：MP3 利用**心理声学模型**，丢掉"人耳实际上听不见"的信息。这是有损压缩的根本哲学——**不追求数学上无损，追求"听感上无损"**。

**掩蔽效应**（Masking，人类听觉的"漏洞"）：
> 一个响的声音，会"盖住"同时出现的小声音，使后者听不见。

**生活例子**：热闹的食堂里，同桌说话声音被周围噪声整个盖住，你完全听不清——这就是掩蔽。噪音响了，小声音就"隐形"了。

**MP3 干的事**：
1. 把声音切成一帧帧（约 26ms）
2. 算出每帧的频谱（第 6 章的东西，这里先听个概念）
3. 找出哪些频率成分"被其他成分掩蔽了"→ 这些直接丢掉或极度简化精度
4. 剩下的部分照常编码

所以 MP3 听起来"差不多"，但文件小了 10 倍。**你最初的问题有答案了：MP3 本身是音频，你要做的是解码分析它，而不是"提取"它。**

**码率（bitrate）**：压缩后每秒多少比特。
- 128 kbps："能接受"（低音糊、高频糙）
- 192 kbps：平时听歌的下限
- 320 kbps：接近无损听感（AAC 用 256kbps 就接近了）

**AAC**：MP3 的后继者，同样有损，同码率下音质略好——这也是为什么视频（mp4 容器）清一色用 AAC 而非 MP3 做音轨。

## 3.4 FLAC：无损压缩

**类比 ZIP**：就像把文本文档打包成 zip 还能原样解压，FLAC 把 PCM 数字"聪明地压缩"（预测+熵编码），**解压后和原始 PCM 逐位一致**。

- 体积约为 WAV 的 50-60%
- 信息零损失
- 收藏无损音乐、或者要"反复处理不变质"时用它

**一条选择铁律**：**你将来做多轮处理（降噪→EQ→压缩），中间文件千万不要用 mp3**——每一轮 mp3 都再丢一次信息，几次之后声音就"脏"了。中间文件用 wav/flac，最后交货再转 mp3。

## 3.5 容器大观：MP4 / MKV / M4A

容器不关心声音怎么编码，它只负责"打包、编目录、同步时钟"：

| 容器 | 能装什么 | 常见搭配 |
|---|---|---|
| MP4 | 视频+多路音频+字幕+章节 | H.264 视频 + AAC 音频 |
| MKV | 什么都能装（开源百宝箱）| 任意视频 + 任意音频（如 FLAC 音轨）|
| M4A | 只有音频的 MP4 | AAC（"mp4 提取音轨"的天然产物）|
| WAV | 通常只装 PCM | PCM（也支持少量其他编码）|

**那"从 mp4 提取音频"到底怎么做？** 两种模式：

```powershell
# 模式 A：不重新编码（copy），瞬间完成，零损失，得到 m4a
ffmpeg -i 视频.mp4 -vn -acodec copy 音频.m4a

# 模式 B：重新编码成 mp3（需要完整解码→再压缩，花时间，有损）
ffmpeg -i 视频.mp4 -vn -b:a 320k 音频.mp3
```

**什么时候用哪个**：只要你想"保留原音质"→ copy；想要"小体积 mp3"→ 重新编码。这就是"提取音频"的全部真相——**根本没有魔法，就是拆箱子或重打包**。

## 3.6 实战：用 ffprobe 读一份"验尸报告"

```powershell
ffprobe 任何音频文件
```

你会看到类似：

```
Duration: 00:03:27.45            ← 时长
Stream #0:0: Audio: aac          ← 编码是 AAC
Sample rate: 44100 Hz            ← 采样率
Channels: 2                      ← 立体声
Bit rate: 189 kb/s               ← 码率
```

**每一行的意义都能对到第 2 章**：采样率=多久记一次，声道=记几路，编码=怎么压缩的。养成习惯：**拿到任何音频文件，第一步 ffprobe**。

## 3.7 格式选择指南（直接抄）

| 你的场景 | 选什么 |
|---|---|
| 学习/自己处理中间文件 | WAV（PCM） |
| 多轮处理的中间品 | WAV 或 FLAC |

| 喂给语音 AI 模型 | 16kHz 单声道 WAV |

## 4.3 第一个脚本：读取"听觉体检报告"

```python
import soundfile as sf
import numpy as np

# ① 读入
data, sr = sf.read("t.wav")
print("数组形状 shape:", data.shape)      # (44100,)        单声道
                                         # (44100, 2)      立体声
print("采样率 sr:", sr)
print("数据类型 dtype:", data.dtype)      # float64，范围 [-1, 1]
print("时长（秒）:", len(data) / sr)       # 点数 ÷ 采样率
print("峰值音量:", np.max(np.abs(data)))  # 最大振幅，1.0 = 满量程
print("均方根 RMS:", np.sqrt(np.mean(data**2)))  # 平均"能量感"
```

**逐行讲解**：
- `sf.read` 返回两个东西：`data`（numpy 数组）和 `sr`（采样率）。**没有 sr，数组就是一堆没意义的数**——同一个数组，44.1kHz 读是 1 秒，22.05kHz 读就是 2 秒
- `data.shape`：一维 `(N,)` 是单声道，二维 `(N, 2)` 是立体声（N=总采样点数）
- 默认读进来是 **float64，范围 [-1, 1]**：1.0 代表"数字满音量"（0 dBFS）

> 📌 **时间 ↔ 下标换算（全书最重要的换算）**：
> **第 n 秒 = 数组下标 `n × sr`**
> 0.5 秒 → `data[:int(0.5*sr)]`；第 3~5 秒 → `data[3*sr : 5*sr]`。所有裁剪、定位都靠它。

## 4.4 立体声：两个数字一起走

```python
left  = data[:, 0]        # 左声道（第 0 列）
right = data[:, 1]        # 右声道（第 1 列）
mono  = (data[:, 0] + data[:, 1]) / 2      # 手动混成单声道
# 更地道：data.mean(axis=1)
```

**实战习惯**：大多数处理和练习先在单声道上进行（少一半数字，直觉更清楚）；需要立体声的场合再双路一起算（所有运算按列广播即可）。

## 4.5 写回去：一个决定成败的细节

```python
sf.write("out.wav", data, sr)
# 想要 16bit 的成品（标准 wav）：
sf.write("out16.wav", data, sr, subtype='PCM_16')
```

**为什么处理时用 float？** 假设音量为 0.1，int16 存起来是 3277（≈0.1×32767）；你乘个 0.5 再除个 0.5，来回取整就丢精度了。**float32/float64 在 [-1,1] 之间做任意运算都不丢精度**——所以"中间处理用 float，最后输出再量化成 16bit"是铁律。

**削波红线**：处理完如果数组里有值超出 [-1, 1]，说明信号"顶穿"了满量程，听感是破音。写文件前自查：

```python
print("最大绝对值:", np.max(np.abs(data)))   # >1.0 就是削波了！
```

# 第 5 章 时域操作：编辑的十八般武艺

> **开场场景**：你录了一段播客，中间咳嗽了两下、开头有 3 秒空白、后半段音量忽大忽小。今天全部解决。这一章的所有操作**都不需要频谱**——直接在时间轴上改数字，是建立信心的第一战场。

## 5.1 先"看见"声音

```python
import matplotlib.pyplot as plt

t = np.arange(len(data)) / sr                     # 时间轴（秒）
plt.figure(figsize=(12, 3))
plt.plot(t[:sr*2], data[:sr*2])                   # 只看前 2 秒，全画会糊
plt.xlabel("秒"); plt.ylabel("振幅"); plt.title("波形图")
plt.show()
```

**读图要点**：x 轴时间、y 轴振幅；**包络**（大轮廓的起伏）= 节奏和响度变化；**细节锯齿** = 音高/音色。语音的波形图长这样：有话音段明显"鼓起来"，停顿段是一条平线——**这就是下一节静音检测的原理来源**。

## 5.2 音量：一切尽在"乘"

**原理**：音量 = 振幅 = 数组整体乘一个系数。

```python
half  = data * 0.5     # -6dB
quiet = data * 0.1     # -20dB
loud  = data * 1.4     # +3dB  ← ⚠️可能削波
```

**把 dB 和系数互算**：

```python
def db_to_gain(db):    return 10 ** (db / 20)     # -6dB -> 0.501
def gain_to_db(g):     return 20 * np.log10(g)    # 0.5   -> -6.02dB
```

**实战：让一段语音"前半小声、后半大声"**（这是你第一个"有规律改造"）：

```python
half_pts = len(data) // 2
data[:half_pts] *= 0.3
data[half_pts:] *= 1.0        # 后半保持
```

## 5.3 削波：为什么话筒爆了就是这声音

**现象**：唱到高音，峰值顶到 1.0——1.1、1.2 的部分被"切平"，波形变成梯形。听感：刺耳、发硬、失真（**破音**）。

```python
peak = np.max(np.abs(data))
print("峰值:", peak)
if peak > 0.95:
    # 抢救方案1：整体压下来（会变小声）
    data = data * (0.9 / peak)
    # 抢救方案2：硬钳位（保响度但引入失真）
    data = np.clip(data, -1.0, 1.0)
```

**从业者铁律**：录音时留 **-6dB 余量**（峰值 0.5 左右），后期再放大，比录爆了再抢救强一百倍。

## 5.4 裁剪、拼接、静音

```python
intro     = data[:2*sr]                          # 前 2 秒
body      = data[2*sr : 5*sr]                    # 2~5 秒
silence   = np.zeros(int(0.5*sr))                # 自己造的 0.5 秒静音
new_audio = np.concatenate([intro, silence, body])
```

**实战：自动静音检测（去口误的第一步）**——用滑动窗口算每一段的"能量"（RMS），低于阈值就是停顿：

```python
frame = int(0.05 * sr)                         # 50ms 一窗
rms = []
for i in range(0, len(data) - frame, frame):
    seg = data[i:i+frame]
    rms.append(np.sqrt(np.mean(seg**2)))
rms = np.array(rms)
is_silence = rms < 0.02 * np.max(rms)          # 阈值：峰值的 2%
print("检测到静音段数:", (np.diff(is_silence.astype(int)) == 1).sum())
```

> 🧠 **为什么用 RMS 而不是"最大值"**：音量是"平均能量感"，单个尖峰值会被一两个爆音误导。RMS 更接近耳朵对响度的感受。

## 5.5 淡入淡出：防"咔哒"声的科学

**先理解咔哒声**：波形值不连续跳变（比如直接切掉中间的一段），相当于在波形上"劈了一刀"——这一刀产生一个极陡的脉冲，频谱上就是一片高频毛刺，耳朵听到"咔"。

**淡入淡出 = 把刀口磨圆**：

```python
n = int(0.5 * sr)                              # 0.5 秒过渡
fade_in  = np.linspace(0, 1, n)                # 线性斜坡
fade_out = np.linspace(1, 0, n)

data[:n]  *= fade_in                           # 开头淡入
data[-n:] *= fade_out                          # 结尾淡出
```

**进阶：交叉淡化（crossfade）做无缝拼接**——两段音乐接缝处互相"让路"：

```python
n = int(0.5 * sr)
ramp = np.linspace(0, 1, n)
tail = audio_a[-n:] * (1 - ramp)               # A 淡出
head = audio_b[:n]  * ramp                     # B 淡入
seamless = np.concatenate([audio_a[:-n], tail + head, audio_b[n:]])
```

> 🎧 **耳朵训练**：拿一段音乐，分别听"直接一刀切"和"0.3 秒交叉淡化"两种接法——前者"咔"一声，后者顺滑。你会永远记住淡入淡出的意义。

## 5.6 归一化：音量标准化

**问题**：三个素材峰值分别是 0.9 / 0.4 / 0.2，拼一起音量忽大忽小。

**归一化（normalize）**：把整段乘个统一系数，让峰值到目标值：

```python
target = 0.9
norm = data * (target / np.max(np.abs(data)))
```

**注意**：归一化只改"整体大小"，不改变"忽大忽小的相对关系"（那需要压缩器，第 8 章）。

## 5.7 反转、回声、循环

```python
reversed_audio = data[::-1]                    # 倒放
echo = np.zeros_like(data)                     # 回声 = 元音 + 延迟的副本
echo[:len(data)] = data
echo[int(0.3*sr):] += 0.6 * data[:-int(0.3*sr)]
```

**倒放为什么恐怖**：语音的反向保留了频谱（音色）但破坏了发音的时间结构——大脑"认不出人话但感觉像人话"，恐怖片最爱。

## 5.8 综合项目 1：给一段录音"整容"

**需求**：你的语音录音有开头 1 秒空白、结尾仓促、音量偏小。

```python
import soundfile as sf, numpy as np

data, sr = sf.read("raw.wav")

# 1) 去头尾静音（阈值法）
frame = int(0.02 * sr)
mask, start_found, end = [], False, len(data)
for i in range(0, len(data)-frame, frame):
    if np.sqrt(np.mean(data[i:i+frame]**2)) > 0.01 * np.max(np.abs(data)):
        if not start_found: start_found, start = True, i
        end = i + frame
data = data[start:end] if start_found else data

# 2) 音量归一化到 0.9
data = data * (0.9 / np.max(np.abs(data)))

# 3) 首尾各 30ms 淡入淡出防爆音
n = int(0.03 * sr)
data[:n] *= np.linspace(0, 1, n)
data[-n:] *= np.linspace(1, 0, n)

sf.write("polished.wav", data, sr)
print("完成，新时长:", len(data)/sr, "秒")
```

**做完记得第 4 步：听 + 看波形**。

## 5.9 本章小结与测验

**要点**：
1. 时域操作 = 数组的切片/乘法/拼接——简单但强大
2. 音量=乘系数；削波=超过 [-1,1]；RMS=真实的响度感
3. 淡入淡出防"咔哒"；交叉淡化做无缝拼接
4. 时间↔下标换算锁死：秒数 × sr

**测验**：

# 第 6 章 频域：声音的 X 光 ⭐全书最关键章节

> **开场场景**：你录了一段人声，里面混着电脑风扇的"嗡嗡"声（50Hz 及谐波）。第 5 章的全部手艺都救不了你——因为"嗡嗡声"和"人声"**在时间轴上完全重叠**，你没法用切片把它们分开。你需要的是一副新眼镜：**频域**。

## 6.1 时域的死角：三个你解决不了的问题

1. **嗡嗡声混在人声里**：时间上叠得严严实实，剪不断
2. **"这声音有点闷"到底闷在哪**：闷=高频少，但"少多少、在哪少"说不清
3. **把一段语音里的音高抬 3 个半音、速度不变**：时域切片做不到

**频域视角**：不看"每个时刻振幅是多少"，而看"整个声音里，各频率各占多少能量"。

## 6.2 傅里叶大思想：任何声音 = 正弦波超级市场

**原理**（傅里叶）：**任何周期信号，都能写成一组频率不同的正弦波的叠加**——每个正弦波有它自己的频率、振幅、相位。

**比喻 1：一道菜 = 食材的组合**。
西红柿炒蛋的美味不是"单一味道"，而是番茄的酸 + 鸡蛋的香 + 盐的咸在时间轴上一同呈现。同理，钢琴的"宽厚感" = 基频 440 的能量 + 泛音 880/1320 的能量 + 一堆更泛的音，煮成一锅。**频谱 = 这道菜的"配方表"**。

**比喻 2：乐高积木**。给你一堆不同长度（频率）、不同颜色深浅（振幅）的正弦波积木，任何波形都能拼出来——包括说话声、小提琴声、迪斯科鼓点。

**这个思想双向打通**：
- **分析（FFT）**：给一段音频 → 拆出"配方表"（频谱）
- **合成（加法）**：按配方表把正弦波相加 → 重建出原声 ← 这正是第 7 章的起点！你现在理解了为什么第 7 章可以"从零造声音"

## 6.3 FFT 实操：拆开看看

```python
from numpy.fft import rfft, rfftfreq

N = 2048                                   # 取一段窗口（2048 个采样点）
segment = data[:N]
amps    = np.abs(rfft(segment))            # 各频率能量
freqs   = rfftfreq(N, 1/sr)                # 对应的频率值

plt.plot(freqs, amps)
plt.xlabel("Hz"); plt.ylabel("能量"); plt.title("频谱")
plt.show()
```

**读图要点**：
- x 轴频率（0 到 sr/2），y 轴能量
- **一个峰 = 一个"有分量"的频率**。纯 440Hz 正弦 → 一根刺；语音 → 一堆低峰+高原；白噪声 → 平铺的一条直线
- 频率分辨率 = **sr ÷ N**。N=2048、sr=44100 时，频率精度 ≈ **21.5 Hz**

**分辨率权衡**（重要）：

| 窗口 N | 频率分辨率 | 时间分辨率 |
|---|---|---|
| 512 | 86 Hz（粗） | 细（11.6ms）|
| 2048 | 21.5 Hz（中）| 中（46ms）|
| 8192 | 5.4 Hz（细）| 粗（186ms）|

> ⚠️ **海森堡式无奈**：窗口越长，频率看得越细，但时间上越"模糊"。经典两难，记住"时间—频率不可兼得"这个 trade-off。

## 6.4 读谱练习：三张脸谱

| 声音 | 频谱长相 |
|---|---|
| 440Hz 正弦波 | 一根孤峰（440Hz），其余全零 |
| 钢琴 A4 | 基峰 440 + 递减的泛音阶梯 880/1320/1760… |
| 白噪声（电视雪花"沙沙"）| 全频段均匀平铺 |
| 语音 | 有起伏的"波浪山头"（共振峰），高频衰减 |

**动手验证**（把上一章的合成拿过来看）：

              + 0.12*np.sin(2*np.pi*1320*t) + 0.06*np.sin(2*np.pi*1760*t))

## 6.5 声谱图：频谱 + 时间 = 视频

单幅频谱是"照片"，声谱图是"电影"——把时间切成窗口，每个窗口做一次 FFT，把结果拼成一张图：

```
横轴：时间   纵轴：频率   颜色深浅：能量
```

```python
import librosa, librosa.display
import numpy as np, matplotlib.pyplot as plt

y, sr = librosa.load("speech.wav", sr=22050, mono=True)
D  = librosa.stft(y)                          # 复数频谱
S = librosa.amplitude_to_db(np.abs(D))        # 转分贝（人耳感）
librosa.display.specshow(S, sr=sr, x_axis="time", y_axis="log")
plt.colorbar(); plt.title("声谱图"); plt.show()
```

**读声谱图入门**：
- 语音的元音是**横向的亮带**（共振峰，低频两三条）；辅音"嘶"是**高频的碎点**
- 音乐里你能看到和弦的竖条纹、鼓点的"竖线爆闪"
- 变调/变速操作在图上会改变"条纹的疏密"

**在 Audacity 里看同一张图**：打开音频 → 视图 → 频谱图。**强烈建议**把玩 10 分钟，你会获得"听不见但看得见"的超能力。

## 6.6 滤波器：在频域里修剪

**定义**：让某些频率通过，削弱或去掉其他频率。原理就是"在频谱上给能量乘一个模板"，但实现不用你操心（ffmpeg/库直接给）。

| 滤波器 | 放行 | 砍掉 | 听感走向 |
|---|---|---|---|
| 低通 lowpass | 低频 | 高频 | "闷、蒙、像隔着被子" |
| 高通 highpass | 高频 | 低频 | "薄、透、去掉隆隆声" |
| 带通 bandpass | 一段 | 两端 | "电话味" |
| 陷波 notch | 除了一小段 | 一小段 | 去 50Hz 嗡嗡完美工具 |

```powershell
# 把语音变成"电话味"（低通 3400Hz，模拟电话带宽）
ffmpeg -i speech.wav -af "lowpass=f=3400" phone.wav

# 去 50Hz 市电嗡声（陷波 50Hz）
ffmpeg -i noisy.wav -af "highpass=f=60" clean.wav
```

**核心用例 1：EQ（均衡器）**。音箱/音乐软件的低音高音旋钮 = 一堆滤波器。想让人声"更亮"→ 高频 +dB；"更厚"→ 低频 +dB。你以后能听懂调音师说的每个词了。

**核心用例 2：去除嗡声**。电脑风扇/市电是**窄带**噪声（就那几根频率刺），在频谱上它们和人声不重叠 → 陷波/高通精准切除。**这就是频域"治病"和时域"切块"的本质区别**。

## 6.7 变速 vs 变调：最容易混的一对

先分清概念（很多人一辈子没搞清）：

| | 改变什么 | 不变什么 | 例子 |
|---|---|---|---|
| **变速** time-stretch | 播放速度 | 音调 | 1.5 倍速听课，老师声音不高不低 |
| **变调** pitch-shift | 音调高低 | 速度 | KTV 原唱升 key，节奏不变 |
| 重采样 resample | 两个都变！ | — | 从 44.1k 强行改成 22.05k 再放，又慢又低 |

**为什么"重采样"会两个一起变**（关键洞察）：音调 = 波形"振动得快不快"，速度 = "时间走得快不快"，而重采样是把时间轴整体拉伸——振动频率和时间轴都改了，所以音调和速度一起变。

**正确做法需要频域魔法**（变调=先变速再在时间轴"补回"速度，反之亦然）。**直接用现成的**：

```python
y, sr = librosa.load("song.wav", sr=22050, mono=True)

y_fast = librosa.effects.time_stretch(y, rate=1.5)      # 提速50%，音调不变
y_up   = librosa.effects.pitch_shift(y, sr=sr, n_steps=4)  # 升4半音，速度不变

sf.write("fast.wav", y_fast, sr)
sf.write("up.wav",   y_up,   sr)
```

> 🎧 **耳朵对照实验**：同一首歌三种处理——① 普通重采样（又慢又低沉）；② time_stretch（快但音调正常）；③ pitch_shift（花栗鼠声但节奏正常）。听完你就一辈子不会混了。

## 6.8 梅尔刻度：为语音 AI 埋的伏笔

**现象**：人耳对频率的感知是非线性的。100→200Hz 感觉跨度巨大，5000→5100Hz 几乎没感觉。

**梅尔刻度（mel scale）**：一种"按人耳真实感知"重新标定的频率轴。常用公式：`m = 2595 × log₁₀(1 + f/700)`。

**意义**：语音识别/合成/AI 全部用**梅尔频谱图**作为输入特征——因为它贴合人耳、信息密度高、还顺带省算力：

```python
mel = librosa.feature.melspectrogram(y=y, sr=sr, n_mels=128)
librosa.display.specshow(librosa.power_to_db(mel), sr=sr, x_axis="time", y_axis="mel")
```

**现在不用深究，但记住三个词**：`STFT → mel 频谱 → 特征`。这是你将来摸到 TTS/语音克隆的必经之路（第 9 章再见它）。

## 6.9 本章小结与测验

**要点**：
1. 任何声音 = 正弦波叠加；频谱 = "配方表"，音色 = 频谱形状
2. FFT 拆解；频率分辨率 = sr/N；窗口长→频率细但时间糊
3. 声谱图 = 频谱的视频，语音/音乐分析的标准视图
4. 滤波器按频率"修剪"；EQ=一堆滤波器；窄带噪声用滤波器切
5. 变速≠变调≠重采样，三兄弟别搞混
6. 梅尔刻度 = 人耳感知的频谱，语音 AI 的输入格式

# 第 7 章 合成：从零"造"出声音

> **开场场景**：红白机的 8-bit 音乐、手机铃声、电子舞曲的"哔哔"音效——这些**不是从任何录音里剪出来的**，而是从数学公式里现场生成的。这一章教你成为"声音的创造者"。

## 7.1 合成 vs 采样

- **采样器（sampler）**：把真实录音糊在键盘上，弹的是"播放录音"
- **合成器（synthesizer）**：不依赖任何录音，用公式现场生成波形

你接下来要做的属于后者。注意：**第 6 章的"任意声音=正弦波叠加"在这里直接变成施工图纸**。

## 7.2 第一个合成音：正弦波

```python
import numpy as np, soundfile as sf

sr = 44100
freq = 440.0              # A4
dur  = 2.0
t = np.arange(0, dur, 1/sr)                 # 时间轴：0, 1/44100, 2/44100, …
sine = 0.5 * np.sin(2 * np.pi * freq * t)   # 公式：A·sin(2πft)

sf.write("A4.wav", sine, sr)
```

**公式拆解**：`A·sin(2π f t + φ)` —— A=振幅（响度）、f=频率（音调）、φ=相位。这正是第 1 章三个基本量。**采样率必须 44100 因为奈奎斯特：要放 440Hz 至少得 880Hz 采样，44.1k 绰绰有余。**

**试听练习**：分别生成 220 / 440 / 880 Hz 各 1 秒。你会听到"同一个音、不同八度"——频率翻倍=升八度，第 1 章的知识落地了。

## 7.3 超越正弦：方波、锯齿波（老合成器的 ABC）

合成器最基本的三种波形，区别全在**谐波配方**：

```python
sine_w   = np.sin(2*np.pi*freq*t)
square_w = np.sign(np.sin(2*np.pi*freq*t))            # 只有奇次谐波(1,3,5…)
saw_w    = 2 * ((freq*t) % 1) - 1                     # 所有谐波(1,2,3…)
```

| 波形 | 谐波配方 | 听感 |
|---|---|---|
| 正弦 | 只有基频 | 纯净、空洞、"哔" |
| 方波 | 奇数倍谐波按 1/n 衰减 | 空心、合成器味（8-bit 游戏机）|
| 锯齿 | 所有谐波按 1/n 衰减 | 明亮、刺、电吉他的"噗噗" |

> 🔬 **验证实验**：用第 6 章的 FFT 画这三种波的频谱——你会亲眼看到"方波只有 1、3、5 倍频的峰"，这就是教科书级"频谱=音色"的现场版。

## 7.4 音符与十二平均律

**十二平均律**：把一个八度切成 12 个等比例半音，相邻半音频率比 = $2^{1/12} ≈ 1.05946$。

**公式**（以 A4=440Hz 为基准）：

```python
def note_freq(semitones_from_A4):
    return 440.0 * 2 ** (semitones_from_A4 / 12)
```

**常用音频率表**（升 12 个半音 = 频率翻倍 = 升八度）：

| 音符 | 半音数(相对A4) | 频率 Hz |
|---|---|---|
| C4 | -9 | 261.63 |
| E4 | -5 | 329.63 |
| G4 | -2 | 392.00 |
| A4 | 0 | 440.00 |
| C5 | +3 | 523.25 |
| A5 | +12 | 880.00 |

**例题**：升 7 个半音（纯五度）频率 ×2^(7/12)≈**1.498**，440→659.25Hz（近似 E5）。

## 7.5 包络 ADSR：从"哔——"到"像乐器"

**问题**：直接生成的正弦波是"啪一下全响、啪一下全停"，像电子闹铃。真实乐器有**起音-衰减-保持-释放**过程。**包络 = 给每个音捏一个"音量随时间变化的形状"，乘上去**。

| 阶段 | 含义 | 钢琴 | 风琴 | 打击乐 |
|---|---|---|---|---|
| A attack 起音 | 0 → 峰值 | 快 | 慢 | 极快 |
| D decay 衰减 | 峰值 → 保持值 | 较快 | 无 | 极快(直接掉) |
| S sustain 保持 | 按住期间的响度 | 低 | 高(一直响) | 无 |
| R release 释放 | 松手 → 0 | 中 | 中 | 快 |

```python
def adsr(n, a, d, s_level, r, sr):
    na, nd, nr = int(a*sr), int(d*sr), int(r*sr)
    ns = max(n - na - nd - nr, 0)
    env = np.concatenate([
        np.linspace(0, 1, na),
        np.linspace(1, s_level, nd),
        np.full(ns, s_level),
        np.linspace(s_level, 0, nr),
    ])
    return env[:n]

note = 0.5 * np.sin(2*np.pi*note_freq(-9)*t) * adsr(len(t), 0.01, 0.1, 0.7, 0.3, sr)
```

> 🎹 **对照听**：把包络换成 `np.ones(len(t))`（无包络）→ 电子闹铃；换成钢琴参数 → 接近钢琴的"敲击感"。包络是音乐性的灵魂，务必亲手调一次。

## 7.6 完整作品：《生日歌》前两句（含低音伴奏）

把音符、包络、拼接全串起来（也复习第 5 章的拼接）：

```python
sr = 22050

def note_freq(n): return 440.0 * 2 ** (n/12)
def adsr(n, a, d, s, r, sr):        # 直接复用上面的包络函数
    na, nd, nr = int(a*sr), int(d*sr), int(r*sr)
    return np.concatenate([np.linspace(0,1,na), np.linspace(1,s,nd),
                           np.full(max(n-na-nd-nr,0), s),
                           np.linspace(s,0,nr)])[:n]

def play(semis, dur=0.35, gap=0.06, vol=0.5):
    t  = np.arange(0, dur, 1/sr)
    tone = vol * np.sin(2*np.pi*note_freq(semis)*t) * adsr(len(t), 0.01, 0.06, 0.7, 0.12, sr)
    return np.concatenate([tone, np.zeros(int(gap*sr))])

# 旋律（相对 A4 的半音数）：Sol Sol La Sol Do' Si
melody = [-2, -2, 0, -2, 3, 2]
# 低音伴奏（节奏减半）：C3 G3 C3 G3
bass_semis = [-21, -17, -21, -17]
bass = []
for bs in bass_semis:
    t  = np.arange(0, 0.82, 1/sr)          # 大约是两拍长度
    b  = 0.4*np.sin(2*np.pi*note_freq(bs)*t)
    b *= adsr(len(t), 0.02, 0.1, 0.7, 0.3, sr)
    bass.append(b)

mel = np.concatenate([play(n) for n in melody])          # 旋律音轨
bass_all = np.concatenate(bass)[:len(mel)]               # 伴奏对齐长度
song = mel * 0.8 + bass_all * 0.5                        # 混音 = 数组相加！
sf.write("birthday.wav", song / np.max(np.abs(song)) * 0.9, sr)
```

**注意混音那行**：`song = mel + bass` —— **"混音"在代码里就是数组相加**。第 6 章"声音=正弦波叠加"在这里以一个完整的作品闭环。

> 🔬 **验收实验**：把 birthday.wav 用第 6 章的声谱图画出来，你会发现旋律在图上变成了"一串横向亮带"——你合成的东方净音，肉眼可见。

## 7.7 人物语音的预告：浊音与清音

人声（以及将来做语音合成）只需要理解两个成分：

| 成分 | 产生 | 波形/频谱特征 |
|---|---|---|
| **浊音**（元音、m/n/l）| 声带振动 | 有基频+谐波串，"亮带" |
| **清音**（s/f/ts、气声）| 气流湍流（不振动）| 无基频，是噪声团 |

**大胆领悟**：浊音 ≈ 合成器的谐波结构（第 7 章的手艺）+ 包络；清音 ≈ 噪声（`np.random.uniform` 那行你已在 6.4 见过）。**语音合成 = 精确控制"何时给谐波、何时给噪声、各多响"**——这个模型是 TTS 的骨架，先记在心里。

## 7.8 本章小结与测验

**要点**：
1. 合成 = 用公式生成波形，与录音无关；正弦波叠加是施工图纸
2. 方波/锯齿波 = 不同谐波配方 → 不同音色（频谱=音色再次验证）
3. 十二平均律：频率=440×2^(半音/12)
4. ADSR 包络让声音"像乐器"；混音=数组相加
5. 语音 = 浊音(谐波)+清音(噪声) —— TTS 的伏笔

**测验**：
1. 方波为什么听起来和正弦波不同？画出它的频谱特征。
2. 升 12 个半音，频率变成原来的几倍？
3. 包络最直接解决了什么问题？
4. "混音"在代码层面是什么操作？

# 第 8 章 效果器：让声音"变形"的原理地图

> **开场场景**：你的录音干巴巴的，想让它"在空旷音乐厅里演唱"、"像电话里传来"、"忽大忽小自动稳定"。这一章给你一张效果器地图：每个效果在数学上到底干了什么。

## 8.1 效果器四大家族

| 家族 | 管什么 | 代表 |
|---|---|---|
| **音量/动态** | 响度的大小与起伏 | 音量、归一化、压缩器、限制器 |
| **时间** | 剪裁/拼接/变速 | 第 5 章全部 + time-stretch |
| **频率** | 声音的成分 | EQ、滤波器、变调 |
| **空间** | 距离感/环境感 | 混响、延迟、合唱 |

## 8.2 EQ：给频率"分档调音量"

**原理**：一堆滤波器，把频谱分成几段（低/中低/中高/高），每段独立增益。

```powershell
# 让人声更"亮"：4kHz 以上 +6dB；更"厚"：200Hz 以下 +4dB
ffmpeg -i speech.wav -af "equalizer=f=4000:t=q:w=1:g=6" bright.wav
ffmpeg -i speech.wav -af "equalizer=f=150:t=q:w=1:g=4" thick.wav
```

**直觉训练**：同一句"你好"，分别耳朵听：低通 300Hz（只剩"嗡嗡的闷葫芦"）、高通 3000Hz（只剩"嘶嘶的骨架"）、正常——你会瞬间建立"频率段=人声的哪些器官"的直觉。

## 8.3 压缩器：自动音量小工

**问题**：人说话忽大忽小（离麦近时爆、转头时飘）。想"响的压下来、轻的抬上去"，让整体音量起伏变小。

**原理**：实时监视电平——超过阈值的部分按比例压小（声音越大压得越狠），再整体补回增益。

```powershell
ffmpeg -i speech.wav -af "acompressor=threshold=-20dB:ratio=4:makeup=6dB" out.wav
```

**理解对比**：归一化=整体乘常数（改变不了起伏）；压缩器=动态改变倍数（驯服起伏）。**做播客/配音，压缩器是第二个必学效果**。

## 8.4 混响：为什么在浴室唱歌这么好听

**物理直觉**：唱歌时，原声 + 墙壁反射回来的无数个越来越弱的回声，叠加在一起 → 空间感。

**实现思路**：混响 ≈ 原始声 + 一堆延迟时间不同、衰减不同的回声副本：

```python
def simple_reverb(x, sr, delays=(0.03, 0.06, 0.11, 0.19), gains=(0.6, 0.4, 0.25, 0.15)):
    out = x.copy()
    for d, g in zip(delays, gains):
        n = int(d * sr)
        out[n:] += g * x[:-n]
    return out / np.max(np.abs(out))
```

**对照听**：干声 vs 加混响——前者"贴脸"，后者"有厅堂感"。浴室瓦片硬反射多 → 混响长；卧室有床垫吸音 → 混响短。这就是为什么浴室歌神。

> 🔬 **实验**：把 delays 全改成 0.2/0.4/0.6 秒（间隔大），听起来就从"混响"变成明显的"回声"（山谷里"A—A—A—"）——混响=密集回声，回声=稀疏混响。

## 8.5 降噪：频域的"去污渍"

**思路（谱减法）**：噪声通常是平稳的（频谱不变），先采一段"纯噪声"样本算出它的频谱形状 → 把它当作"模板"，然后从整段音频的频谱里"减掉"模板 → 剩下的就是人声+很少噪声。

**实践**（两个现成方案）：
1. Audacity：框选一段纯噪声 → 效果 → 降噪 → "获取噪声轮廓" → 全选 → 再来一次
2. Python：`pip install noisereduce`，`nr.reduce_noise(y=audio, sr=sr, y_noise=noise_sample)`

**局限性**：噪声不平稳（比如风扇变档、街道忽静忽闹）时效果打折——这也是为什么"降噪"永远是工程难题，但**原理你已掌握**：频域里剪掉噪声成分。

## 8.6 效果链：把干声变"电话里的电台主持人"

**组合才是真实用法**：低通（电话味）→ 压缩（稳定）→ 混响（空间）：

```powershell
ffmpeg -i dry.wav -af "lowpass=f=3400,acompressor=threshold=-20dB:ratio=4,aecho=0.7:0.6:40|70:0.3|0.2" radio_phone.wav
```

**分步验证**（专业习惯）：每加一个效果就听一次、看一次频谱——你会清楚"这一步是谁干的"。

## 8.7 本章小结与测验

**要点**：
1. 效果器四家族：动态/时间/频率/空间
2. EQ=分频段调音量；压缩器=驯服音量起伏（≠归一化）
3. 混响=密集衰减回声；回声=稀疏混响
4. 降噪=在频域减掉噪声模板；效果链=分步组合+逐步验证

**测验**：
1. 归一化和压缩器处理的区别是什么？
2. 混响和回声的本质区别是什么？
3. 降噪的基本原理一句话是什么？
4. 为什么处理效果时建议"一次加一个，边加边听"？

# 附录 D 各章测验答案

**第 1 章**：
1. 女声 220Hz 高，正好高一倍（一个八度）。
2. -6dB（20×log₁₀(0.5)≈-6.02）。
3. 泛音=基频整数倍的附加频率成分；它们的强弱分布决定了频谱形状=音色。
4. 反相消噪：生成与环境噪声相位相反（差180°）的波，叠加抵消。

**第 2 章**：
1. ≥40kHz（奈奎斯特：2×20k）。
2. 8bit × 6dB = 48dB（96→144dB）。
3. 人声主要能量在 4kHz 以下，16kHz 足够且省存储/算力。
4. 混叠（aliasing）；音频里表现为高频被伪造成不存在的低频怪声，危害是声音失真。

**第 3 章**：
1. 同样的 MP4 容器，M4A 只装音频不装视频。
2. 心理声学（掩蔽效应）：丢掉人耳听不见的频率成分。
3. 每一轮 mp3 压缩都再次有损，误差不断累积叠加（"脏"）。
4. `-vn`=不要视频轨；`copy`=不重新编码直接复制音频轨（无损、秒完成）。

**第 4 章**：
1. 44100/44100=1 秒，到 88200/44100=2 秒，即第 1~2 秒。
2. int16 中间运算反复取整会累积误差；float 在 [-1,1] 内运算不丢精度。
3. (30×44100, 2) = (1,323,000, 2)。
4. 写出时长/音调可能不对（sr 是"解释数组"的标尺，丢了就乱）。

**第 5 章**：
1. ×0.25（-6dB 两次）。
2. 峰值会被个别爆音欺骗；RMS 反映"平均能量感"，更接近听感。
3. 拼接点波形突变 → 产生高频毛刺（"咔"）；用交叉淡化（互相淡出淡入）根治。
4. 归一化是按峰值比例缩放（自动），手动调音量是乘固定系数——归一化保证不削波且统一峰值。

**第 6 章**：
1. sr ÷ N；要 10Hz 精度，N ≥ sr/10（如 44100/10≈4410，取 8192）。
2. 嗡嗡声是窄带（频率固定、时间上叠着人声），滤波能精确"按频率"切除；时域剪不掉时间重叠的成分。
3. 重采样改的是采样率：时间轴和频率都会被拉伸 → 速度、音调一起变；变速只改时间不改音调（需要频域处理）。
4. 低通 3400Hz（高通 300Hz 封底更完整）＝电话带宽限制，属于滤波/EQ。

**第 7 章**：
1. 方波含 1、3、5…奇次谐波；正弦只有基频——频谱不同=音色不同。
2. 2 倍（12 个半音 = 一个八度）。
3. 消除"爆响-骤停"的生硬感，让音有起音-衰减-保持-释放的轮廓（更像乐器、不爆音）。
4. 数组相加：`混合 = 音轨A + 音轨B`。

**第 8 章**：
1. 归一化=整体乘一个常数（不动起伏）；压缩器=随电平动态改倍数（镇压起伏）。
2. 混响=延迟时间短而密集（听起来是"空间"）；回声=延迟长而稀疏（听得出"重复"）。
3. 先采样一段纯噪声得出噪声频谱模板，再从整段频谱里减掉它。
4. 逐步验证才知道"哪个效果产生了什么变化"，出问题能定位；一次全上则无法归因。
